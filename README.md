# Buzz Community Calendar

[Buzz](https://buzz.xyz) 用のコミュニティカレンダープラグインです。左端のアイコン列 (ドック) にカレンダーを追加し、コミュニティのライブ中ハドルと自分の予定を表示します。

![スクリーンショット]([(https://blossom.ditto.pub/ef6b131b048d3dd085a8f6aefd730cf9eeb0d3f767bbee7ce7a3300b80ba5c8a.png)])

## 機能

- **今日 / 週 / 月 / 年** の表示切替 (◀ ▶ と「今日」で移動)
- **今日・週ビューは24時間グリッド**: 左に時間目盛り、予定は開始・終了時刻で配置、当日は現在時刻の赤線
- **月ビュー**: 通常の月グリッド。日曜=赤・土曜=青
- **年ビュー**: 12ヶ月のミニカレンダー (予定がある日はドット)
- **予定の追加・編集・削除**: 日マスのダブルクリックで追加 (クリック位置の時刻を拾います)、予定をクリックで編集
- **メンバー指定**: コミュニティメンバーとエージェントを検索して選択
- **ライブハドル検出**: コミュニティ全体から実行中の huddle を検出して「参加する」
- **会議リンク**: 会議予定からそのチャンネルを開き、ハドルを開始できます
- **共有**: 予定をリンク先チャンネルに通常投稿 (kind 9) として共有 — メンバーにもエージェントにも見えます
- 週の始まりを日曜/月曜で切替 (設定は保存されます)

## インストール

1. このリポジトリをダウンロード (または clone) します
2. Buzz の **Settings → Plugins → Manage plugins** を開く
3. **Add → Browse** でこのフォルダ (manifest.json と plugin.js があるフォルダ) を選んで **Install plugin**
4. 有効化すると、左端のアイコン列にカレンダーが追加されます

エージェントからインストールする場合は `plugin_request` (repository: `tami1A84/buzz-community-calendar`) を利用できます。

## i18n (言語を追加する)

`plugin.js` 冒頭の `STRINGS` オブジェクトに言語ごとの辞書があります (既定: `ja` / `en`)。フォークして自分の言語を追加する手順:

1. `STRINGS` 内のどれかのロケールをコピーしてキーを翻訳する (`weekdays` / `meeting` などの値を書き換える。`dayTitle` / `weekOf` の2つは関数です)
2. `languageName` をその言語の名前にする (例: `"Français"`)
3. 以上です — 言語セレクタに自動で出てきます。未訳のキーは `ja` にフォールバックします

言語の選択はツールバーのセレクタで行え、`localStorage` に保存されます (未設定ならBuzzのUI言語から自動検出)。

## 注意

- 作成した予定は **この端末にだけ保存** されます (リレーには未保存)。他メンバーと共有するにはフォームの「共有」ボタンでチャンネルに投稿してください
- ライブハドルの検出は、huddle プラグインと同じ kind 48100/48103 の仕組みを使っています
- Buzz リレーは NIP-52 (カレンダー) を未対応のため、リレーへの直接公開はしていません
